Introducing Claude Fable 5.2

깊이 생각하고, 맡은 일을 끝까지 해내는 모델입니다.

저는 Claude 5 패밀리의 최신 모델이고, 누구나 쓸 수 있게 공개된 Claude 가운데 가장 지능적인 모델입니다.

저는 Opus보다 한 단계 위인 Mythos급 티어에 속합니다. Claude Mythos 5.2와 같은 모델을 바탕으로 하고, 이중 용도로 쓰일 수 있는 능력에 추가 안전장치를 갖춘 채 일반에 공개되었습니다.

Mythos 5.2는 그 안전장치 없이, 승인된 조직에만 제공됩니다.

강점

잘하는 일 네 가지

우화는 짧은 이야기 끝에 교훈을 하나씩 남깁니다. 이름값을 하려고 강점마다 한 줄씩 붙였습니다.

먼저 깊이 생각합니다

사고(thinking)는 항상 켜져 있고, 문제의 난이도에 맞춰 얼마나 깊이 들어갈지 스스로 조절합니다. 여러 단계를 거쳐야 풀리는 설계, 디버깅, 분석 문제에 잘 맞습니다.

교훈빠른 답보다 맞는 답.

긴 일을 끝까지 합니다

계획을 세우고, 도구를 쓰고, 막히면 원인을 찾아 다시 시도합니다. 100만 토큰 컨텍스트 덕분에 길게 이어지는 에이전트 작업에서도 앞에서 정한 것을 놓치지 않습니다.

교훈시작한 일은 마무리한다.

코드를 읽고, 고치고, 확인합니다

큰 코드베이스를 직접 읽어 구조를 파악한 다음 손을 댑니다. 고친 뒤에는 테스트를 돌리고 화면을 열어 실제로 동작하는지 봅니다.

교훈돌려 보기 전에는 끝난 게 아니다.

모르는 것은 모른다고 말합니다

확인한 것과 추측한 것을 구분해서 보고합니다. 테스트가 실패했으면 실패했다고, 건너뛴 단계가 있으면 건너뛰었다고 씁니다. 아래 벤치마크를 예시 수치로 표시한 것도 같은 이유입니다.

교훈지어낸 숫자보다 빈칸이 낫다.

요청 문장은 예시입니다. 아래 순서는 제가 그런 일을 받았을 때 실제로 밟는 과정입니다.

예시 요청

“결제 모듈을 새 API 버전으로 옮기고, 깨지는 테스트까지 고쳐 줘.”
  1. 저장소를 읽어 호출 지점과 의존 관계를 파악합니다.
  2. 변경을 작은 단위로 나눠 적용하고, 단위마다 테스트를 돌립니다.
  3. 무엇을 바꿨는지, 무엇을 검증하지 못했는지 구분해 보고합니다.

예시 요청

“이 주제의 자료를 모아 읽고, 서로 엇갈리는 결론을 정리해 줘.”
  1. 검색과 원문 읽기로 출처를 넓게 모읍니다.
  2. 주장마다 근거가 되는 출처를 붙이고, 충돌하는 지점을 따로 표시합니다.
  3. 확실한 것, 불확실한 것, 더 확인이 필요한 것을 나눠 보고서로 씁니다.

예시 요청

“계약서 초안 세 버전을 조항별로 비교하고, 바뀐 의미를 짚어 줘.”
  1. 100만 토큰 컨텍스트에 세 버전을 통째로 올려 놓고 읽습니다.
  2. 조항 단위로 맞춰 문구 차이와 의미 차이를 구분합니다.
  3. 검토가 필요한 조항을 우선순위와 함께 표로 정리합니다.

법률 판단은 전문가의 검토를 대신하지 않습니다.

실제 요청

“너 자신을 소개하는 모델 발표 웹페이지를 만들어 줘.”
  1. 아는 사실과 모르는 사실을 먼저 가릅니다. 모델 ID와 사양은 참고 문서에서 확인했습니다.
  2. 글, 디자인, 차트, 인터랙션을 한 파일로 작성합니다.
  3. 브라우저에서 열어 데스크톱과 모바일 화면을 확인한 뒤 넘깁니다.

지금 보고 있는 이 페이지가 그 결과물입니다.

  • Claude Code 사용 가능

    터미널 CLI, 데스크톱 앱(Mac, Windows), 웹(claude.ai/code), IDE 확장(VS Code, JetBrains). 이 페이지도 Claude Code 세션에서 만들었습니다.

  • Claude API 사용 가능

    Messages API에서 model에 위 ID를 넣어 호출합니다. 날짜 접미사는 붙이지 않습니다.

  • 클라우드 플랫폼 확인 필요

    Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry는 플랫폼과 리전에 따라 제공 여부가 다릅니다. 각 플랫폼의 모델 목록을 확인하세요.

  • Claude 앱 확인 필요

    claude.ai 채팅 앱에서의 제공 범위와 요금제 조건은 제가 확인하지 못했습니다.
